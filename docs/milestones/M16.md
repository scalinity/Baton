## 10. Risks and decisions this milestone settles

- **“Cold” is observable.** An already registered target, manually adapted plan or continued
  sibling session cannot be presented as a from-scratch pass.
- **Observation takes time.** A successful three-milestone run that never paused has not met
  this milestone's window-boundary criterion. Record it incomplete rather than simulating the event.
- **A real defect ends the clean trial.** Preserve artifacts, report the cause and stop with
  an actionable remainder. Do not quietly patch code or give a second human instruction and call
  the run unattended. A legitimate scope-drift escalation is evidence of the guard, not a pass
  for the three-milestone unattended criterion.
