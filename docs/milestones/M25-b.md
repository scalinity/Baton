# M25-b — A check killed from outside is run again, not reported as main-broken

## 1. Identity

- **ID:** M25-b. **Objective:** Baton's standing check, when it ends by a signal it did not send and
  with no failing scenario, is run once more instead of being recorded as a failure.
- **User-visible result:** a check interrupted by something outside Baton does not park the project
  `main-broken`; a check that fails, or is interrupted twice, still reaches the person.
- **Size:** Small to Medium, about 2 hours; high effort.

## 4. Requirements, scope, non-goals

**The measured finding.** On 2026-10-01 at 22:51:37 one session's `pkill -f "tests/run.sh"` killed
the two standing checks Baton was running, for M15-c's merge (`aed2d5ef`) and M15-e's (`ff0d9710`).
Each runner wrote exit 143 (SIGTERM); neither output had a `FAIL` line, both stopping mid-scenario
(`tests/run.sh: line 198: 68231 Terminated: 15`). The tick at 22:52 recorded each check
`outcome: failed, exit: 143` in its `consumed` event and parked the project `main-broken` twice,
which holds every new dispatch for Baton until a person answers. Baton's own deadline kill records
`timed-out`, so this exit came from outside. M25 stops the cause it measured; this milestone makes the
next outside interruption, from whatever cause, cost a rerun rather than a false park.

**Scope.**

1. **Interrupted is its own outcome.** A runner that exits by a signal Baton did not send (status
   above 128, Baton's deadline not reached) with no failing scenario in its output is `interrupted`,
   not `failed`.
2. **Run it once more.** An interrupted check is restarted once on the same revision, through the
   existing start path and under the existing deadline; its result is the check's.
3. **Twice is a person's.** A second interruption is recorded `interrupted` and raises a park whose
   detail says the check could not finish and why, never `main-broken`, which means the code failed.

**Non-goals.** No change to what a failed or timed-out check means, to the deadline, or to the chain.
